**Also seen in the same workflow (assumption):** `build.yml` has no checkout step, and the input tree has no `Dockerfile`. The job may therefore fail on every push no matter what the code does. **ASSUMPTION:** `inputs/` is the whole repository. If it is only part of it, this point is void.
